# Claudex

> Universal conversation viewer for Claude Code

- 🔍 **Full-Text Search** - SQLite FTS5 powered search
- 📝 **Universal Templates** - Supports all Claude Code versions (V1.x, V2-mixed, V2.0+)
- 🎯 **Smart Rendering** - Markdown, code blocks, diffs, tool usage
- 📊 **Analytics** - Session stats, file operations, message distribution
- 📋 **Export** - JSON, HTML, and TXT formats
- 🚀 **Modern Stack** - React + Vite + Fastify + SQLite
